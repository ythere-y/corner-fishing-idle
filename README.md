# 背包钓鱼手记 🎣

贴在桌面角落的一本「背包客钓鱼手记」——TA 在外面环游世界，边走边钓；你在这边，边挂机边看 TA 的旅程。Godot 4.6 · 2D。

> 世界观：一位刚离职/间隔年的年轻背包客（Jim 或 Ganie，由你选），背包一甩说走就走，
> 一路从家门口的河湾钓到深海、钓到没信号的溶洞。桌角这方小水塘，就是 TA 寄回来的「远程连线」。
> 玩法内核不变（自动挂机 / 收集 / 离线奖励），仅重新包装成「旅程手记」外壳。详见 `docs/lore_backpacker.md`。

## 形态

- 默认运行态是**普通无边框透明覆盖窗**：窗口尺寸铺满当前屏幕可用区，但不触发 macOS 系统全屏 Space；挂机画面固定在右下角，背包 / 图鉴 / 任务 / 设置等复杂面板在主窗口中央以大 modal 打开，不再挤占挂机区域。
- 置顶 + **逐像素透明**窗口（GL Compatibility 渲染器，无灰底）。
- **可拖动 / 缩放**：在场景空白处按住左键移动挂机组件，拖边角缩放；默认右下角，位置和大小存档。菜单面板可按住标题栏拖动。
- 空白透明区**鼠标穿透**到桌面；复杂菜单在主窗口中央展开。
- 边缘羽化 shader，融进任意壁纸。

## 玩法

- **自动挂机钓鱼**：抛竿 → 等待 → 浮标咬钩下沉 + 涟漪 → 自动上鱼**入鱼篓** → 手动卖出变现，循环往复。
- **10 个钓点＝背包客走过的 10 个旅程站点**（第1站中国·家门口河湾 → 第10站斯洛文尼亚·溶洞尽头，路线：中国×4 → 菲律宾 → 马来西亚 → 新西兰 → 澳大利亚 → 冰岛 → 斯洛文尼亚），各有专属鱼池与随机事件，按累计渔获解锁；切换钓点改变鱼池、订单建议、事件与背景。地理跨度不再是 bug，是「TA 到底跑了多远」的正当理由。
- **219 种鱼 / 6 档品阶**（普通→神话），每条带生态标签（河/湖/溪/海/深/冷/夜/保护）决定出没钓点；权重抽取；**体重**影响价值，标「大·/巨物·」体型。缺专属图标时回退按品阶的通用鱼图标，不崩。
- **桌面宠物 🐱**：渔夫旁的小馋猫，上鱼时偶尔扒拉；2% 概率叼走鱼篓里**最廉价的一条杂鱼**（卖价 ≤30，珍藏/订单/锁定绝不动）当趣味事件，计入「猫税」统计与成就。
- **活水族箱 🐠**：「鱼缸」页签——把心爱渔获放进缸里（最多 8 条），缸内鱼沿正弦路径游动、按方向翻转，点鱼看它的纪录（最大体重/累计/首捕日/变体），可捞回鱼篓；鎏金/七彩变体带脉动光晕。每条 +观赏卖价加成（封顶 +5%）。最契合桌面摆件的健康非数值长线。
- **专注奖励**：窗口失焦且无操作时累计连续「专注」，满 25 / 50 分钟下一竿强制升级渔获（保底极品★★，再保底鎏金变体）。回焦有 60 秒宽限窗（快速卖鱼一趟不折进度），窗外操作折算保留 80%；每日封顶按**实际兑现**计（25 / 50 分钟档各占一次；仅满篓停竿等两档都攒着时合并为一次兑现），50 分钟档兑现后本段重新起算——离开越久回来越有惊喜。
- **随机事件**（数据驱动 7 种）：鱼汛 / 晨雾 / 寒潮 / 顺水鱼群 / 涨潮 / 漂流木箱 / 保护鱼放流，低干扰，按钓点触发，叠加咬钩/价值/运气修正。
- **昼夜时段**（按真实时钟）：黎明 / 白昼 / 黄昏 / 夜晚自然流转；金色时段（晨昏）咬钩更勤、渔获略增值，夜晚静谧但偶有大物；场景随时段轻染色，HUD 显示。零存档。
- **星级品质**：无 / 上品★ / 极品★★ / 完美★★★，价值 ×1/×1.8/×4/×8，由**鱼饵**决定概率。
- **稀有变体**：每条鱼独立 roll 变体（普通/斑斓/鎏金/七彩，2.5%/0.4%/0.08%——约 1/40、1/250、1/1250 竿的三层惊喜节拍），价值 ×1/2/5/12，与星级正交。图鉴按种记录已见变体——**219×3=657 格**收集轴，超长线护城河（Chillquarium 式）。**诱饵/窝料**成长线按级抬高变体出现率（vbias 分档：越稀有的花色提升越多，七彩吃满偏置），是这条收集轴的专属杠杆。**彩鳞（v15，分三种）**：重复钓到已点亮的变体折 1 枚**同档鳞**（斑斓鳞/鎏金鳞/七彩鳞），在鱼种详情卡的变体墙用同档鳞**定向点亮同档缺格**（按品阶 3/4/5 枚一格；七彩格只认重复七彩，防低档金流刷穿最稀缺格）——把最后几格从纯赌命变成可规划目标。
- **鱼篓背包**：起始 20 格、阶梯扩容至 **100 格**（14 级；55 格后的 6 档 25 万→950 万，是毕业期的大额金币去向，也是签约后更大的珍品缓冲区）；满篓暂停上钩（满篓兜底：自动折价兑现，留贵兑贱，珍藏不动）；**排序（最新/价值/品阶/重量）+ 订单鱼筛选**；收藏锁（锁定不被卖出/交付）。
- **成长**：多条线各管一轴——鱼竿（稀有度：缩短等待 + 提升高阶概率 + 鱼价加成，成本 400×1.7^级）；**属性装备链**（鱼线→绕线轮→浮漂→探鱼器→钓鱼笔记→钓鱼手套，逐步解锁，+1/+10/+100 真实扣金币，分别提供技巧/稳定/速度/反应/感知/生态/追踪/力量等角色属性；角色属性作为二级修正映射到钓鱼结果：速度/反应→一竿周期，生态/感知→品阶权重，技巧/稳定→星级，感知/生态→变体，反应/技巧→双钩，力量/稳定→体型尾部）；鱼饵（星级：蚯蚓→红虫→活虾→秘制饵）；鱼钩（产量：双钩，一定几率一次再上一条）；诱饵/窝料（稀有变体：无窝料→碎米窝→酒米窝→麝香窝料，按级抬高斑斓/鎏金/七彩出现率）。**升级体感**：装备页数字明牌（每行具体概率 + 鱼竿"当前→下一级"）；购买任意升级后**下一竿试竿保底**（鱼竿=高运气一竿 / 鱼饵=保底新★级 / 鱼钩=必双钩 / 窝料=保底斑斓），花钱立刻亲眼见效。
- **每日订单**：每天 1 单，4 类（指定鱼种 / 指定品阶 / 大物≥Wkg / 完美品质），交付未锁渔获按鱼价 ×2.5；需求量随品阶分层（大众鱼 8~12 条起，恒按鱼篓容量封顶），鎏金/七彩/★★★ 珍稀**不自动交单**（完美单豁免★★★）；HUD 常驻进度，跨日刷新。**周目标 / 每周巨物赛**奖励锚定昨日卖鱼收入的 10% / 8%（保底原线性公式），巨物赛**累计夺金**跨周沉淀（连着两档成就）。
- **流动鱼贩**：随机限时收购时段，卖价 ×1.5（HUD 金色提示）。
- **鱼贩合约（自动贩卖，v14）**：60,000 金一次性签约，**在线**满篓时按市价自动带走一条**最便宜的杂鱼**（普通花色 · ≤★ · 稀有以下 · 非巨物；收藏与未交付订单目标不碰，想留的杂鱼上 🔒 即可）；篓里全是珍品时照常咬钩、新渔获走满篓折价兜底——签约后挂机不停产。合约本身永不碰珍品；离线结算不走合约（仍为折价兜底，按「留贵兑贱」处理，珍稀建议上收藏锁）。买断后可随时暂停。
- **图鉴**：219 种鱼，每种记录累计数 + 最大体重 + 首捕日 + 变体收集 + 长期徽章；钓点页显示各钓点鱼种收集进度。
- **成就**：41 项（渔获/财富/收集/品阶/品相/装备/陈列/变体/猫税/长线断点/周赛线），多数达成发金币，超长线渔获档为纯称号（陈列物奖励管线待做，见 BACKLOG）。
- **离线收益**：回屏弹「离线小结」面板（时长 / 渔获数 / 最值钱一条 / 珍稀清单——含溢出段已兑金的）；上限 **12 小时**（图鉴 ≥145 种扩 **24 小时**）、50% 效率；按昼夜时段**分段结算**（夜行限定鱼在夜段真的会来，每种每次至多 2 条），先填满背包空格，溢出部分按 0.5 折价自动兑成金币（留贵兑贱，收藏/订单鱼不动）。
- **音频**：UI / 抛竿 / 入水 / 咬钩 / 捕获 / 金币 / 升级 音效 + **分层环境音床**（多条循环音按「钓点生态 × 昼夜时段」配方淡入淡出；缺素材优雅退化为单层水声，详见 `docs/audio_asset_rules.md`）；设置可调静音 / 主音量 / 音效 / 环境音。

- **9 页签**：背包 · 图鉴 · 订单 · 成就 · 统计 · 钓点 · 鱼缸 · 装备 · 设置（升级与设置都并入页签）。

### 游戏内「测试模式」（开发期，逻辑见 `test_mode.gd`）

设置页顶部「测试模式（开发用）」开关切换 **游玩 / 测试** 两态。测试模式下设置页展开「🧪 测试台」：
左侧开发入口可直接打开属性面板；属性面板可编辑金币（翻倍/减半）、装备来源层与宠物状态；测试台可强制昼夜时段、钓鱼提速（×3/×10/即时）、改金币、+1/拉满装备与背包、绕线轮升降/设级、给指定鱼（鱼种×星级×变体）、
样本包/清空鱼篓、解锁全部钓点/点亮全图鉴、召唤鱼贩/重置订单/充能专注、立即触发随机事件。

**仅本会话生效、不写档**：进入即冻结磁盘存档，退出（切回游玩模式）从磁盘重载正式档、丢弃全部测试改动；
重启天然回到正式档——正式存档永不被测试数据污染。HUD 右上常驻「🧪测试」角标提示当前在测试模式。

### 开启新存档（开发期）

设置页底部「开启新存档」：删磁盘存档（主档/.bak/.tmp）+ 全状态复位默认开局（复用 `SaveSystem.apply({})`
迁移默认）+ 落盘干净档 + 重看引导（新：重新走一遍「开场故事→选角色」）。**两点确认防误触**（首点变红警示，3.5s 内再点执行）。开发阶段存档无价值，可随时清空重开。
