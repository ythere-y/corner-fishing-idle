## 1. 结论摘要

**总体健康度：核心循环健康、短线体验达标偏快，但所有内容轴一致性"前倾"——首日透支、中后期真空。** 前 2 小时（Steam 退款窗口）的密度远超标准，问题不在"内容不够"而在"发放太快"；修复几乎全是改数字和小改动，无需动架构。最值得改的五件事：

1. **鱼竿线在第 ~50 分钟撞悬崖**：Lv11 等待封顶后回本从分钟级一步跳到 4.8 小时，恰落在退款窗口内——基数 200→400、增速 2.0→1.7、等待折扣 0.06→0.04 三个常数联动即可拉平。
2. **10 站旅程骨架一夜耗尽**：任何竿级首个 8 小时离线（≈2,341 条渔获）就越过全部解锁阈值，此后 80+ 小时零解锁事件——后段阈值几何拉伸即可铺满首周。
3. **657 格变体收集轴尾部纯赌命**：单个 T5 七彩格期望 ~90 小时、零保底零兑换——加"重复变体折彩鳞、定向兑换缺格"把 300h+ 尾巴压进 25~40h。
4. **毕业期金币真空**：四条侧线约 1 小时收入即买满、鱼竿 Lv16~17 后回本破 24h 硬顶，此后每小时 92 万金零去处——需要可重复消耗品 + 荣誉陈列物两类新去向。
5. **20h→100% 之间没有任何可规划目标层**：成就 ~10h 清空、图鉴断点从 4.6% 直跳 100%、周活动奖励萎缩成 2 分钟收入——把断点成就、长线成就、奖励锚定收入打包成一个"20~40h 目标层"。

## 2. 本次建立的数值设计标准（量表）

*白话说明：「回本时间（payback）」= 一次升级花的钱 ÷ 它带来的每秒新增收益，即多久赚回本；「sink」= 金币回收口（花钱的地方）；「几何/指数增长」= 每级按固定倍数变贵。*

| ID | 标准 | 核心量化指标 |
|----|------|-------------|
| S1 | 升级成本-收益双指数结构 | 成本增长率 r∈[1.07,1.12]；里程碑倍增固定 ×2；有效购买间隔每小时增幅 ≤15% |
| S2 | 回本时间分阶段区间 | 0~30min:10s~2min；30min~5h:2~15min；5~20h:15min~2h；20h 后:2~8h；主线升级硬上限 ≤24h |
| S3 | 多线错峰与三层购买目标 | 并行 4~6 条线，首购成本比 5~10×；短期目标 2~3 个 / 中期 1~2 个 / 长期 ≥1 个全时在场 |
| S4 | 墙=减速带非悬崖 | 首墙 ≥45~60min；全程 3~5 面；墙高 3~10×（硬顶 20×）；翻墙路径提前 ≥10min 可见 |
| S5 | 首会话密度与事件真空上限 | 首鱼 ≤30s；前 15min 事件 ≥10 个；事件间隔 P90 前 1h ≤3min → 20h 后 ≤1 过夜 |
| S6 | 图鉴发放曲线匹配总时长 | 1h/25%、5h/50%、20h/85%；最后 15% 绑条件而非纯低概率；100% 完成 25~40h |
| S7 | 子集切分与断点奖励阶梯 | 断点 10/25/50/75/90/100%；75% 后装饰类奖励占比 ≥70%；末格不卡点 |
| S8 | 稀有惊喜三层节拍与保底 | 小惊喜 1/40~60 竿、大 1/300~500、史诗 1/3000~5000；硬保底 ≤2× 期望；重复稀有 3~4 换 1 定向 |
| S9 | 收入配比与事件脉冲 | 主动卖鱼 40~60%、订单 20~35%、事件 5~15%、离线 10~25%；单次事件=5~15min 收入等值 |
| S10 | 订单溢价与吞吐限制 | 普通单 1.5~2.5×、黄金单 3~5× 且 ≤池 10~15%；槽 3~5 个、刷新 1~4h；订单收入 ≤40% |
| S11 | 水槽吸收率与终局无限 sink | 推进期吸收 80~95%；毕业期可重复 sink ≥1（单次=5~20min 收入）+ 荣誉 sink（20~50h 收入） |
| S12 | 被动加成感知下限与封顶 | 单条 ≥+5%；系统级单源 ≤+50%；全被动总封顶 +100~200%；乘法链 ≤2 层 |
| S13 | 数字膨胀节奏 | 鱼价跨度 ≤1000×（建议 200~500）；任意 5h 窗口速率增幅 ≤4×；UI ≤7 位数 |
| S14 | 离线三态模型 | 桌面挂机=100%；真离线 50~65%、上限 10~12h（里程碑扩 24h）；离线稀有判定照常次数减半 |
| S15 | 零强制交互 | 强制操作=0；不操作惩罚=0；纯挂机 ≥ 满操作 60%；每小时注意力 ≤90s |
| S16 | 主动收益天花板 | 满操作 ≤ 挂机 1.5~1.8×（硬顶 2.0）；主动加成为 10~20min 短时 buff |
| S17 | 感官打扰预算 | 高显著动效 ≤2 次/h；默认音效 OFF；系统通知=0；错过折损=0% |
| S18 | 专注模式奖励边界 | 专注贡献 ≤15% 总收益；单次番茄 ≈15~25min 挂机收益等值；中断折算 ≥80%；专注期弹窗=0 |

## 3. 分维度诊断详情

严重度按核查员终审（severityAdjust）排列。文件:行号均指仓库现行代码。

### 3.1 前期节奏

#### 【高】鱼竿线首小时买穿等待封顶，回本从分钟级一步跳到 4.8 小时——首日悬崖而非减速带（S2/S4）

- **证据**：成本 = 200×2^(lv-1)（main.gd:1822）；等待系数 maxf(0.4, 1-(lv-1)×0.06) 在 Lv11 触底（main.gd:791、2186）。活跃卖鱼下 Lv1→11 累计成本 204,600 金、逐级购买时间累计仅 ≈48 分钟。Lv11 后单级只剩 +8% 卖价与少量权重上移（合计 ×1.10/级），边际回本序列：Lv8→9=31 分、9→10=51 分、10→11=82 分、**11→12=288 分（4.8h）**、12→13=549 分（9.2h）——在 Lv11 处一步 ×3.5 的不连续跳变，对 S2 该阶段 15 分钟带宽超标约 19 倍，此后每级 ×1.9 无界增长，第 2~3 天破 S4 的 20× 硬顶。注释自认"成本增速 2.0 > 产出增速 1.25、后期形成自然墙"（main.gd:1820-1821），但实测产出增速在 Lv11 因等待封顶从 ~1.22 骤降到 ~1.10——悬崖的位置与形状偏离了设计者自己声明的"渐进减速带"意图。附带：ui_panels.gd:1934 仍宣传"咬钩更快"，Lv11 后为虚假描述。撞墙点还正好落在退款窗口内。
- **调整**：三常数联动——①基数 200→**400**（首购 ≈31.6 秒收入，仍在 S2 首段）；②增速 2.0→**1.7**（Lv1→11 累计 ≈114,600、触达推迟到 2h+）；③等待折扣 0.06→**0.04**（main.gd:791 与 2186 两处，封顶从 Lv11 推迟到 Lv16），Lv12~16 回本平滑落在 ~24/34/50/72/104 分。同步：tools/balance_probe.gd:10 与 :43 的硬编码、ui_panels.gd:1934 文案。

#### 【高】钓点解锁全线前倾：首个过夜离线即 9/10 站全解锁，此后 80+ 小时零解锁事件（S5/S6/S4）

*本条为三位发现员从前期节奏、收集轴、长线目标三个口径独立命中的同根问题，三次核查均确认为 high，此处合并。*

- **证据**：解锁阈值 80/180/250/300/450/600/800/1200 条累计渔获 + 末站 species 110（spot_data.gd:36-142）。离线渔获（含满篓溢出折价部分）全部计入 lifetime_catches（main.gd:2203/2219）：8h 离线 rod1≈2,341 条、rod8≈3,650 条——**任何竿级第一晚就越过全部 catches 阈值**。活跃玩家 2h 退款窗口内可达第 3~5 站，且第 3~10 站中 7 站无背景图、回退河湾主图（scene_painter.gd:402-414），与 VISION.md:29 "在售钓点都有背景图"的 DoD 冲突。唯一后置的 cavern_pool（110 种 ≈50.2% 图鉴）约 1~2 天达成，其后到图鉴毕业的全程再无解锁事件——10 站旅程（支柱②骨架）只覆盖全周期 <5%。BACKLOG/ROADMAP 无"首日全开系有意"的任何记录。
- **调整**：前 4 档 80/180/250/300 不动（保住 S5 首会话密度与退款窗口覆盖）；后 4 档拉成过夜节拍：**450→1,500、600→3,000、800→6,500、1,200→12,000**（约每 1~2 个过夜开一站，铺满首周）；cavern_pool species **110→140~150**（64~68% 图鉴，保持终点站身份），此数由制作人在两位核查员给出的区间内拍板。同步：validate_game.gd:1013-1104 硬编码的 80/300 断言；mountain_stream、urban_pond 两张背景图仍在退款窗口可达、必须有图（本已在 DoD/ROADMAP 内，优先级提前）。老玩家不回锁（已解锁列表持久化，save_system.gd:60）。

#### 【中】三条有限侧线首购 1~4 分钟内全亮、首日全线买满，次日起愿望清单只剩鱼竿（S3）

- **证据**：首购成本红虫 800 / 宽门钩 2,000 / 碎米窝 3,000（fish_data.gd:304/312/322），对开局 ≈760 金/分的收入，相邻线首购比仅 ×2.5/×1.5（S3 要求 5~10×），三系统第 3~5 分钟齐开。四线满级总投入 256,250 金，按 rod3~5 收入只要 1~3.4 小时——第 2 天起中短期购买层清空。fish_data.gd:319 注释自称 LURES 是"专属长线 coin sink"，实际 ≈27 分钟收入即买满，与自述意图矛盾。（首扩鱼篓 100 金的秒买是 main.gd:70 明示的有意设计，不计入违规。）
- **调整**：首购错峰——红虫 800 保持、宽门钩 **2,000→6,000**、碎米窝 **3,000→30,000**（酒米窝须同步抬价避免档梯倒挂，如 18,000→45,000）。末档抬高——秘制饵 24,000→**60,000**、双叉钩 60,000→**180,000**、麝香窝料 90,000→**400,000**、鱼篓末三档 4,000/10,000/25,000→**8,000/30,000/90,000**。改后有限 sink 总池 ≈84 万（酒米窝同步后 ≈92 万）≈ 首日收入 2~3 倍，侧线目标延展到第 2~3 天。回本复核：秘制饵 ≈42 分、双叉钩 ≈2.2h、麝香按档间增量 ≈8.2h，均落在 S2 对应阶段带宽内，不会变"不划算"。

#### 【中】首日图鉴推进约 60~80%，收集长线被第一天透支（S6）

- **证据**：rod1 两万抽实测品阶分布 {0:57.5%, 1:25.2%, 2:10.8%, 3:4.9%}（validate 实跑），~585 条/h；叠加钓点全开（9 池首日可用）与离线照常掷图鉴（入篓与溢出段均 _dex_record，main.gd:2199-2218），首日 4h 活跃 + 8h 离线 ≈4,680 抽，T0~T3 共 177 种（=81% 图鉴）大面积入手。对活跃轮转玩家首日 ≈60~80%（纯挂机不动窝的玩家 ≈20%，不超标），S6 要求 5h/50%、20h/85%。
- **调整**：主修 = 采纳上面的钓点阈值拉伸（首日可见鱼池收敛到 4~5 个，首日图鉴自然回落到 ~45-50%）；辅修 = 离线 roll 到"未收录鱼种"时 50% 概率改抽同池已收录同阶鱼（main.gd:2199 处，需补"同池同阶无已收录鱼则回退原抽"的边界）——保住"回来看离线新鱼"的惊喜（S14 新鱼率 ≥50%），避免睡一觉图鉴 +30%。

#### 【低】每日订单/周目标奖励与主收入量级脱节：t0 订单 ≈ 开局收入的 3~13 秒（S9）

- **证据**：首日只出 t0/t1 单（orders.gd:47），need 1~5 条，奖励 = 卖价 ×2.5 → 均值 ≈150 金（P10~P90 ≈30~220），对开局 ≈734 金/分是噪声级；周目标 rod1 奖 4,500 ≈6 分钟收入；日订单收入占比 <0.5%（S9 带宽 20~35%）。核查确认首日目标密度并不靠订单独木支撑（另有巨物赛、钓点解锁阶梯、图鉴/成就流），故降为低严重度，但 README 明示订单是 ×2.5 经济溢价的常驻触点，量级落空属实。
- **调整**：谨慎版两步——①need 上调但**须按背包容量封顶**（起始 20 格，need≥21 物理不可能；建议 t0 8~12 / t1 5~8 / t2 3~5，或改进度累计式交付）；②日 1 单改 **3 槽订单板、每 4h 刷新 1 槽**（S10 带宽内），倍率 2.5× 不动。目标：订单消化渔获 5~15%、收入占比 15~30%。注意交付放弃了原卖价，净溢价是 +1.5×。

### 3.2 升级曲线

#### 【中】balance_probe 的"回本"口径系统性偏低 1.5~4.5 倍，且第四条线（诱饵）从未被度量——所有调参决策建立在虚低数字上（S2）

- **证据**：鱼竿回本用 成本÷该级总收入 而非升级增量（balance_probe.gd:64）——Lv8→9 显示 7.0 分、边际口径实为 31.4 分（×4.5）；鱼饵/鱼钩的增量恒对 0 档基线差分而非相邻档（:71、:81）——活虾 8.4 显示 vs 12.3 实际（×1.5）、秘制 16.9 vs 29.3（×1.7）、倒刺 14.4 vs 28.7（×2.0）、双叉 44.9 vs 119.6（×2.7）。三条升级线均强制逐档购买（main.gd:1840/1859/1878），相邻档边际是唯一正确口径。全脚本无 FishData.LURES 引用。
- **调整**：**先修探针再调参（本报告其余建议的验收都依赖它）**——①鱼竿段改 cost÷(income(lv+1)−income(lv))；②饵/钩段 delta 改与上一档差分；③补诱饵段：变体期望倍率 E=1+0.13×(1+vbias)，按相邻档 ΔE×当前收入算边际；④探针内 5.25 基数、200×2^n、+8%/级三处硬编码与主代码同步（若采纳鱼竿改 400×1.7^n，此处必须跟改）。

#### 【低】蚯蚓星级通过率 [0.08, 0.02, **0.05**] 第三级反高于第二级，四档鱼饵中唯一不递减，疑似两位数字写反（S1）

- **证据**：fish_data.gd:303 蚯蚓 probs=[1.0, 0.08, 0.02, 0.05]，其余三档均严格递减；roll_quality 逐级失败即停（fish_data.gd:337-341）。validate 实跑（seed=9）精确复现 8,000 竿仅 12 次★★、1 次★★★。该库对每个刻意取舍都有注释，此处无注释、且头注与 validate 断言均表达"越高越稀有"的单调意图。
- **调整**：fish_data.gd:303 改为 **[1.0, 0.08, 0.05, 0.02]**（对调后两位）：P(★★★) 乘积不变，P(≥★★) 从 0.16% 升到 0.40%，期望价值仅 +0.5%，不扰动开局经济，validate 全部断言仍通过。

### 3.3 经济平衡

#### 【高】毕业期 sink 真空：可重复 sink=0、荣誉 sink=0，唯一无限线（鱼竿）回本 Lv16~17 破 24h 硬顶后，≈92 万金/小时再无去处（S11）

*两位发现员分别从经济平衡与长线目标命中；一位核查员维持 high（撞墙时点早于预期、命中自declared 长线支柱），另一位建议 medium（陡墙系有意设计、鱼竿有品阶权重残值、真实墙钟更晚）。报告从严取 high。*

- **证据**：全库金币支出恰 5 处（main.gd:1749/1831/1849/1868/1887）；四条有限线总沉没 256,250 金 ≈ rod5+秘制 61 分钟收入。鱼竿 Lv11 等待触底后产出增速降到 ~×1.09/级、回本环比 ×1.83~1.91：精算蚯蚓口径 Lv14→15=33.4h 破限、满配口径 Lv16→17=43.6h 破限。此后满配 15,370 金/分（≈92.2 万/h，探针实跑）零出口：无可重复消耗 sink、无荣誉陈列 sink，图鉴百分比断点奖励 0 个；钓点解锁不花钱，订单/周常/赛事/成就全是进水口。毕业玩家（桌面挂机 8h/天 ≈700 万+/天）一至两周内撞墙。
- **调整**：三件套——①鱼竿 Lv15 起成本换挡 ×2.0→**×1.5**（cost=int(200×2^14×1.5^(lv-15))），回本增速降到 ~×1.36/级，多活约 3 级；②新增可重复消耗 sink：「特制窝料/豪华窝料」单次 **100,000~150,000 金**（≈满配 6.5~10 分钟收入，落 S11 的 5~20min 区间），效果为 10~30 分钟短时 buff（vbias+1 或 wait×0.85，符合 S16 加速器定位）；③新增荣誉 sink：纯陈列物阶梯（水族箱布景/金鱼竿皮肤/黄金浮标雕像）定价 **50 万→200 万→1,000 万**（1,000 万 ≈10.8h 满配收入，兼顾 S13 的 7 位数 UI 预算；若走 25M 档 ≈27h 亦在 S11 区间但需 8 位数 UI，二选一）。

#### 【中】辅助收入全线萎缩成噪音：奖励随竿级线性、产出随竿级 ×1.25 指数，直卖占比 >95%（S9）

### 3.7 支柱契合

#### 【中】"一次点击清零专注"与"约 2 分钟必须回来卖鱼"互相抵消：两根支柱的机制在数值上打架（S18/S15）

- **证据**：任何点击/按键即清零专注计时且无折算（main.gd:726-730, 2089-2092，S18 要求 ≥80% 折算、现值 0%）；**仅切回窗口（FOCUS_IN）也清零**（main.gd:2293），比原述更严。而在线挂机默认鱼篓 20 格约 2 分钟即满、满篓直接停竿停产（main.gd:781；注释"挂机永不停产"与该门控相悖，属僵尸注释）——不回来点，产出归零；回来点，专注归零。代码自证矛盾：注释称专注奖励是"给一直开着一个正向理由"，却与 2 分钟满篓停产互斥。
- **调整**：三处小改——①清零改折算：`_focus_away_t *= 0.8`（对齐 S18 下限，20 分钟工作+快速卖鱼循环 3~4 轮仍能攒满）；②回焦后 60 秒宽限窗，窗内点击不清零（容纳一次 ≤15 秒的快速卖鱼）——**必须同时覆盖 main.gd:2293 的 FOCUS_IN 路径**，否则切回窗口瞬间已清零、宽限窗失效；③额度按消费计（见 3.5 双扣条目）。

#### 【中】满级窝料把"变体惊喜"通胀成 ~11 秒一次的刷屏，击穿不打扰的感官预算（S17）

- **证据**：麝香下变体率 29.6%/竿、每条必发 2.8s toast（屏幕小提示条，main.gd:916-918）→ rod10 每 ~11 秒一条；星级 toast 另叠（秘制饵 P(≥★★)=24.5%）；闪光 _flash 合计 ≈1.45%/竿 ≈15.7 次/h，超 S17 的 ≤2 次/h 约 7 倍。且 _toast/_flash 均无 focus_mode 守卫（对比 _popup 有，main.gd:1178-1179）——专注/安静模式照常轰炸；_set_focus 注释明写"抑制飘字"意图，缺守卫是疏漏。刷屏窗口恰落在玩家刚卖完鱼、注意力切回工作的头几分钟。
- **调整**：感官三改（不动掉率）——①变体 toast 门槛 vr≥1 提到 **vr≥2**，斑斓降级为浮漂 _popup 飘字（自动获得守卫）：toast 率从 29.6%/竿降到 5.6%/竿（≈59 秒一次）；②_flash 加 **1800 秒冷却**（每小时至多 2 次，会吞掉部分破纪录庆祝，可接受）；③给 _toast 庆祝类调用与 catch 路径 _flash 补 focus_mode 守卫。掉率侧与 3.4 的 VARIANT_PROBS 调整联动拍板。

#### 【低】订单交付自动吞掉最贵匹配鱼（含未上锁的鎏金/七彩）：逼玩家养成"每条稀有立刻手动锁"的警觉习惯（S15）

- **证据**：交付按卖价降序直删前 need 条（orders.gd:151-152, 178-181），唯一豁免是手动锁；species 单也只比对 id，目标鱼种的七彩变体同样被吞。最强场景：失焦挂机期间（支柱③）钓到七彩，玩家从未见到 toast，回来点交付即永久失去入缸/收藏机会，完全无防御窗口。旁证：满篓兜底注释"绝不动玩家珍藏"（main.gd:982）——保护珍藏的伦理未贯彻到订单。
- **调整**：自动选取池默认排除 **var≥2 与 q=3**（perfect 类订单豁免 q=3 否则无法成单）；因排除凑不够 need 时 toast 提示"有稀有渔获可交单，请手动确认"（需新增一个小确认框）。
