# 角色主视觉概念稿（渔夫 + 猫）

> 用途：定角色形象与风格方向的**概念稿**，供团队参考，非运行时资产。
> 运行时的猫为 `assets/art/pets/` 下 96×96 透明帧，由 `scene_painter.gd` 按状态加载；本文档不改动这些资产。

## 风格锚点

- 方向：画意水彩 · 河湾港（`river_bend`，第 1 站 家门口河湾）
- 基调：暖色为主，青灰点缀；角色作为整体废弃海港冷色调场景中的**暖色视觉焦点**
- 与主视觉的关系：主视觉走「废弃海港·青绿 + 琥珀」，角色保留干净明亮的水彩感，形成冷暖对比
