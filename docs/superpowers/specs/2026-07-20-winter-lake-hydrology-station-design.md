# 冬泊湖水文台设计

## 状态与定位

- 日期：2026-07-20
- 设计状态：Owner 已认可核心循环、进度、趋势和前三图联动
- 范围：第 2 站冬泊湖的长期地图系统，以及河湾、雪线溪谷之间的第一条联动

水文台是一条与玩家当前位置并行运行的长期挂机线，不是第二套钓鱼。玩家在冬泊湖布设一枚浮标后，可以前往任意地图正常钓鱼；浮标继续在线与离线观测，跨图渔获和事件只负责加速。

## 设计原则

1. 同一时间只运行一枚浮标，使布设地点成为有意义的选择。
2. 时间保证进度，匹配的跨图行为提供额外进度；不匹配不处罚。
3. 三个钓位逐步开放，必须先在冬泊湖留下实际活动记录。
4. 普通冬泊湖钓鱼始终可用；水文台不成为地图进入门槛。
5. 不加入每日截止、消耗门票、耐久、损坏或错过惩罚。
6. 深水潭使用河湾终章奖励，使永久凭证产生真实玩法效果。

## 核心循环

```text
在冬泊湖满足本地条件
→ 解锁水文台与芦苇岸
→ 选择一个地点布设唯一浮标
→ 玩家在任意地图正常挂机
→ 真实时间提供基础观测
→ 匹配渔获、纪录和事件追加观测
→ 完成三页钓位记录
→ 获得本地能力并开放下一钓位
→ 深水总报告向雪线溪谷输出冷水窗口记录
```

## 布设与迁移

- 三个地点为芦苇岸、乱石湾、深水潭。
- 每个地点保存独立的永久进度；迁移不清零、不收金币。
- 浮标按观测周期工作，基础周期暂定 2 小时。
- 玩家可随时指定下一地点；当前周期完成后自动迁移，避免即时来回切换，同时不损失进度。
- 若目标地点在迁移时仍未满足条件，浮标留在原地点继续工作，迁移请求保留到条件满足。

## 解锁条件

### 芦苇岸

- 已造访冬泊湖。
- 在冬泊湖累计钓到 20 条鱼。
- 冬泊湖图鉴至少发现 4 种。

### 乱石湾

- 完成芦苇岸总报告。
- 冬泊湖图鉴至少发现 8 种。
- 钓到一条达到该鱼 `wmax` 60% 的湖泊鱼。

### 深水潭

- 完成乱石湾总报告。
- 完成周叔一次性终章并取得 `old_boat_pass`。
- 记录过一次寒潮事件。

寒潮历史必须在水文台功能上线后可靠记录；不能只检查当前正在发生的随机事件。

## 三个钓位的记录页与奖励

### 芦苇岸

1. 鱼群活动：时间为主，夜行鱼和晨雾加速；完成后显示冬泊湖当前昼夜鱼情。
2. 岸边物种：湖泊物种、夜行鱼和原生淡水鱼推进；完成后小幅提高冬泊湖未发现鱼权重。
3. 芦苇岸报告：自动汇总，不额外交付；冬泊湖等待时间缩短约 8%，开放乱石湾。

### 乱石湾

1. 重量样本：接近 `wmax` 的渔获贡献更多，任意地图个人纪录可提供少量对照数据；完成后显示大物活跃程度。
2. 掠食鱼活动：湖泊掠食鱼贡献最多，其他地图中高品阶掠食鱼可提供对照；完成后小幅提高冬泊湖中高品阶权重。
3. 乱石湾报告：冬泊湖体型分布尾部约提高 8%，开放深水潭勘测说明。

### 深水潭

1. 深水温层：时间、冷水鱼和寒潮推进；完成后显示冬泊湖水温趋势。
2. 稀有窗口：匹配趋势或事件中的渔获显著推进，其他地图冷水和高品阶鱼提供对照；完成后显示是否适合追踪稀有鱼。
3. 深水总报告：匹配水文条件时，冬泊湖稀有鱼权重相对提高约 6%；永久获得 `winter_cold_window_record`。

奖励必须在各自适用条件下生效，不叠成无条件全局幸运或售价倍率。

## 观测点数

内部统一使用观测点，UI 展示进度与来源，不展示复杂公式。首轮平衡基线：

- 每 6 分钟真实时间：1 点。
- 匹配普通渔获：2 点。
- 匹配优质样本：5 点。
- 新个人重量纪录：8 点。
- 匹配事件首次记录：12 点。
- 每页需求：按内容设为 60–100 点。

纯时间约 6–10 小时完成一页；主动追踪可缩短到约 3–5 小时。离线累计沿用游戏现有离线上限，不另设每日上限。完成一页后的多余点数带入同钓位下一页；最终页完成后停止累积。

## 水文趋势

水文趋势是确定性的长期背景，不是可通过重启刷新的随机 Buff。趋势由存档稳定种子和真实时间段计算，每段约持续 2–4 小时：

| 趋势 | 目标与效果 |
|---|---|
| 水草活跃 | 常见湖鱼、未发现鱼权重提高 |
| 猎食巡游 | 掠食鱼、中高品阶鱼权重提高 |
| 冷水下沉 | 冷水鱼、深水鱼权重提高 |
| 大物贴底 | 体型分布尾部提高 |
| 平稳水况 | 无额外效果，作为节奏缓冲 |

趋势主要修改鱼池权重或体型分布，不额外乘售价、速度和全局幸运。单次趋势对目标出现率的相对提升控制在约 10%–20%。趋势与随机事件可同时匹配；匹配时事件照常生效并提供大量观测，不匹配时双方各自正常运行。

### 信息逐层揭示

- 芦苇岸完成：只显示当前趋势的模糊描述。
- 乱石湾完成：显示趋势名称、目标类型和大致剩余时间。
- 深水潭完成：显示当前趋势、效果强度、下一趋势类型和大致开始时间。
- 获得溪谷冷水样本后：下一趋势开始时间的预报更准确。

## UI 与反馈

水文台不增加永久底栏入口。选中冬泊湖时，在旅行地图或钓点页出现“水文台”本地行动位。

水文台面板包括：

- 当前浮标地点、当前记录页、总进度。
- 三张钓位卡及明确的锁定条件。
- 当前周期预计结束时间和排队迁移地点。
- 最近三条观测日志。
- “迁往此处”按钮。
- 完成后的水文报告印章和简化水文总图。

HUD 平时只显示一行低频状态，例如“乱石湾浮标 · 重量样本 43/80”。只有完成记录页、开放新钓位或迁移结束时弹提示。

离线小结必须解释来源，例如：观测时长、匹配样本数量和获得点数，不能只显示百分比。

世界地图上的冬泊湖按状态显示普通站点、工作水波或有利趋势图标。悬停展示当前浮标、记录页和已研究趋势；布设操作仍在水文台面板中完成。

河湾周叔终章

## 状态与模块边界

水文台应使用独立数据与逻辑模块，不继续扩张 `main.gd`：

- 静态真值：钓位、记录页、点数来源、趋势配置。
- 运行逻辑：解锁检查、时间推进、渔获／事件观测、迁移、趋势计算。
- UI：只读取公开状态并调用布设／迁移接口。
- 存档：保存解锁、各页点数、已领奖、当前地点、周期时间、迁移请求、事件历史和跨图永久记录。

老存档首次加载时水文台保持未解锁，不追溯历史渔获，以免上线后瞬间跳过内容；现有 `old_boat_pass` 必须能被识别。

## 验证与验收

自动回归至少覆盖：

- 玩家离开冬泊湖后，在线和离线时间仍推进浮标。
- 匹配跨图渔获追加点数，不匹配渔获不扣分。
- 三个钓位按条件顺序开放。
- 迁移在周期边界发生且不丢进度。
- 重启不能改变同一时间段的趋势。
- 页间溢出正确，最终页不无限累积。
- 船牌控制深水潭，深水报告写入冷水窗口记录。
- 老存档迁移、存档往返和损坏字段回退安全。

视觉验证覆盖水文台三种锁定状态、正在观测、迁移排队、完成报告、世界地图趋势和离线小结。

首版成功标准：玩家能在冬泊湖布设后前往河湾继续钓；跨图样本有可见贡献；三个钓位逐步开放；船牌产生真实能力；深水完成后雪线溪谷出现新的长期目标。

## 非目标

- 多浮标并行、浮标升级、耐久、损坏、耗材和付费加速。
- 真实气象 API 或联网水文数据。
- 精确温度模拟和向玩家暴露底层概率。
- 在水文台首版内完整实现雪线溪谷放流簿。
